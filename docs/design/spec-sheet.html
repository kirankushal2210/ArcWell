Motion

From the Nessie motion video, adapted to Arcwell and Android. Things that change should move, not jump. Short and functional, with one bigger moment saved for the app's biggest achievement.

TokenDurationUsed for
micro120 mspress feedback, tick fill, toggles
standard200 msnumber rolls, cards appearing, tab and segment changes (about a fifth of a second)
sheet280 msbottom sheets and the side menu opening
big moment600 msworkout summary only (see below)
easingMaterial 3 emphasized: cubic-bezier(.2, 0, 0, 1). In the app: React Native Reanimated.
Rule 1 · Numbers roll
kcal left
Calories left, set weights, timers and bodyweight roll to the new value in 200 ms, so you see the change. Equivalent of SwiftUI's numeric text transition.
Rule 3 · The big moment
0kg lifted
Push day done · 52 min
New best · bench 72.5 kg × 8
Finishing a workout is Arcwell's biggest moment, so the summary (F4-12) gets the only long animation: the ring fills, volume rolls up, and any new best slides in. A strong haptic on Android. No confetti, flames or badges (D24).
Rules 4 and 5 · Loading and background
Skeletons, not spinners. A soft outline of the screen pulses while it loads, so it feels faster (see States).
No animated background. The video's slow-moving shader background is left out: it conflicts with Arcwell's solid-colour, minimal direction (D24) and costs battery on budget Android phones. If ever added (e.g. splash only), it must pause in battery saver and stay still with reduced motion.
Reduced motion. With Android "Remove animations" on, every transition becomes an instant change and skeletons stop pulsing. This page does the same.

Rules every screen follows

One primary action per screen, in the bottom half.
Colour means something: cyan training, amber nutrition, violet recovery, blue for actions.
Text left-aligned; centre only single empty-state messages.
Numbers are tabular and roll when they change.
No gradients, glows, glassmorphism or heavy shadows.
No red for missed targets; red only for errors and destructive actions.
No streaks, XP, badges or confetti.
No emoji as icons; no invented logo or tagline.
