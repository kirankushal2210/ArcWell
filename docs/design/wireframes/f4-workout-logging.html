Arcwell — Wireframes: F4 Workout logging

The screen athletes use most, so it gets the most care. Goals: log a set in one or two taps, always show last session's numbers, work one-handed between sets, and never lose a workout when the signal drops. Patterns adapted from Hevy and Strong (see competitor-research.md).

Primary action / completedSecondary / editableDecision or open question

F4 · Before the workout

Today (or Train tab) → Workout preview → Start

F4 · During the workout

Log sets → automatic rest timer → next set · adjust numbers · swap or skip exercises · leave and come back

F4 · Finishing

Finish → confirm if sets are unticked → summary → how it felt → saved (coach notified)

Open questions from these wireframes

  • F4-03: Track effort per set (RPE / reps in reserve) as an optional column, or only the overall "how did it feel" at the end? Recommendation: end-of-workout only in v1 to keep the table simple; coaches can set RIR targets in the plan text.
  • F4-05: kg only, or allow lb as a setting?
  • F4-07: Should coaches be able to lock specific exercises so they can't be swapped?
  • F4-12: Keep "Share" (an image card of the summary) in v1, or defer?
  • Not designed yet: supersets / circuits, timed exercises (planks, cardio), and bodyweight-only reps without weight. Recommendation: support timed and bodyweight sets in v1, supersets in v1.1.
