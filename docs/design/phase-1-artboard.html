How it is built
  1. Depth by step, not shadow. The screen is bg, the card is surface, the stat tiles and button outline sit one step up on raised.
  2. Spacing has rhythm. 4 between a label and its value, 8 between tiles and inside a group, 16 card padding, 24 between the card's groups.
  3. Blue means "act". Electric blue appears only on the primary button and the question's rule. Cyan marks status ("To review").
  4. Numbers are neutral. Changes such as −0.6 kg stay muted grey. A loss is not automatically good, and a missed target is never red.
  5. Left-aligned throughout. Name, stats and question all start on the same 16 dp edge.
